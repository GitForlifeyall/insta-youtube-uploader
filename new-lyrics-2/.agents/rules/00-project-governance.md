# LyricalVideo project governance

Always read `@/AGENTS.md` before researching, planning, editing, or executing commands in this workspace.

The following constraints are non-negotiable:

- Do not change Template 1, Template 2, Template 3, Brat Minimal, or YT Hindi Type default visual styles unless the creator explicitly requests a change to that specific template.
- Never edit `.env` or print secrets, cookies, API keys, or authentication values.
- Use `.venv310\\Scripts\\python.exe` for Python work that needs the project environment.
- Preserve the no-lyrics guard and one-pass FFmpeg composition rule.
- Ask for approval before deletion, recursive moves, overwriting meaningful files, package installation, external uploads, or Git history rewriting.
- Do not scan video, audio, image, or font directories unless the task needs named assets. Ask the creator to shortlist visual options instead.

Use a narrow file scope. First inspect the relevant files, explain the intended change, then make the smallest safe edit and verify it.
