# Antigravity workspace customization

This folder is the Antigravity adapter for LyricalVideo.

- `rules/` contains always-on project safeguards and brain-loading instructions.
- `agents/` contains specialized, workspace-scoped agents.
- `skills/` contains focused slash-command skills. Invoke them as `/project-start`, `/prepare-song`, `/investigate-render`, `/save-decision`, or `/weekly-review`.

Start each new Antigravity task with `/project-start <task>`. Keep project permissions in review/approval mode. Do not grant outside-workspace file access unless you deliberately need the separate Creator Vault.
