# Rule: Small Tasks Must Always Be Delegated to Codex

- If any task is a **small task** (single-file tweak, quick bug fix, formatting, typo fix, minor script, isolated test, or simple documentation update), **always delegate it to Codex** or process it as a Codex-directed task.
- Refer to [CODEX.md](file:///CODEX.md) and [SMALL_TASKS.md](file:///SMALL_TASKS.md) for full task categorization criteria and execution workflow.
